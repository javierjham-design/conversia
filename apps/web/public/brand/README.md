# Logos de TuBot.cl

Colocar aquí los archivos de marca con **exactamente** estos nombres (el código ya los referencia).
Formato preferido: **PNG con fondo transparente** (2x para que se vea nítido en pantallas retina).

| Archivo | Qué es | Dónde se usa | Tamaño sugerido |
|---|---|---|---|
| `tubot-horizontal.png` | Logo horizontal a color (ícono + "TuBot.cl") | Nav de la landing, login, header legal | alto ≥ 160 px |
| `tubot-vertical.png` | Logo vertical a color | Reservado (hero / material) | alto ≥ 320 px |
| `tubot-icon.png` | Solo el ícono (bot en burbuja) | App / marcas pequeñas | 512×512 |
| `tubot-mono.png` | Logo horizontal monocromático | Footer (se invierte a blanco sobre navy) | alto ≥ 160 px |

## Favicon / ícono de pestaña
Colocar el ícono como **`apps/web/src/app/icon.png`** (cuadrado, 512×512). Next.js lo toma
automáticamente como favicon y como ícono al agregar a pantalla de inicio.

## Paleta (ya cargada en `globals.css`)
- Deep Navy `#0B1D3A` → `navy-900`
- Electric Blue `#2563EB` → `brand-600`
- Cyan `#00D4FF` → `accent-400`
- Soft Teal `#14B8A6` → `teal-500`
- Light Gray `#E5E7EB` → `gray-200`
